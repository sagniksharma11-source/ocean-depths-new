# Ocean Depths — Frontend Odyssey

**Live Demo:** [https://ocean-depths-seven.vercel.app](https://ocean-depths-seven.vercel.app)

## About
Ocean Depths is an immersive, scroll-driven web experience that takes 
users on a cinematic journey from the sunlit surface of the ocean to 
the crushing darkness of the Hadal Zone, 11,000 meters below sea level.

## Features
- Sonar loader counting from 0 to 11,000m
- Custom glowing cursor with lag ring
- Animated SVG jellyfish per zone (Moon Jelly, Mauve Stinger, Crown Jelly, Big Red Jelly, Comb Jelly)
- Sperm whale swimming across the Midnight Zone
- Three.js bioluminescent particle field (2000 particles)
- GSAP ScrollTrigger depth animations
- Web Audio API dynamic soundscape
- CSS 3D flip cards
- Typewriter narrative
- Zone HUD indicator
- Depth meter tracking 0–11,000m
- Mobile responsive design

## Technologies
HTML5, CSS3, JavaScript, GSAP, ScrollTrigger, Three.js, Web Audio API, Google Fonts (Cinzel, Inter, Share Tech Mono), Vercel

## Sections
1. Surface (0m) — Hero + parallax sun rays + animated jellyfish
2. Twilight Zone (200m) — Creature cards + Moon Jelly + Mauve Stinger
3. Midnight Zone (1000m) — Three.js particles + Crown Jelly + Sperm Whale
4. Abyssal Plain (4000m) — Flip cards + pressure counter + Big Red Jelly
5. Hadal Zone (6000m) — Typewriter + conservation stats + Comb Jelly
