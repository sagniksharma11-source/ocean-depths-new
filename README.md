# Ocean Depths — Frontend Odyssey

**Live Demo:** https://ocean-depths-omega.vercel.app

## About
Ocean Depths is an immersive, scroll-driven web experience that takes 
users on a cinematic journey from the sunlit surface of the ocean to 
the crushing darkness of the Hadal Zone, 11,000 meters below sea level.

## Features
- Three.js bioluminescent particle field
- GSAP ScrollTrigger depth animations  
- Web Audio API dynamic soundscape
- CSS 3D flip cards
- Typewriter narrative
- Depth meter tracking 0–11,000m

## Technologies
HTML5, CSS3, JavaScript, GSAP, ScrollTrigger, Three.js, Web Audio API

## Sections
1. Surface (0m) — Hero + parallax sun rays
2. Twilight Zone (200m) — Creature cards
3. Midnight Zone (1000m) — Three.js particles
4. Abyssal Plain (4000m) — Flip cards + pressure counter
5. Hadal Zone (6000m) — Typewriter + conservation stats
